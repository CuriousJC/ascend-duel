Full-bleed pictures for the playing cards, one per card per element.

Keyed by filename stem: `card/jab-fire.png` is the key `jab-fire`, which is what
`data/card_art.json` writes in its `Art` field. Committed at the card's own 200x280.

`docs/art/card_art_prompt.MD` is what they are generated from. There is no default
face here on purpose — a card with no picture draws as it always has.
