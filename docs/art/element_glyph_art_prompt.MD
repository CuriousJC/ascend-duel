# Element glyph art prompt

Five symbols, one for each element of a card game — **fire, ice, lightning, earth, arcane** — drawn
as bold game icons. Each is laid over a small square button of polished jade or amber stone, so
**attach one jade and one amber button**: every symbol has to read clearly on both, at a glance, at
small size.

---

## The prompt

High-resolution digital illustration of **five bold game icons**, one per file, each a single
chunky symbol on a **fully transparent** background. Think of the element icons in a polished mobile
card game: simple, confident, instantly recognizable shapes — **icons, not illustrations**.

### Every icon

- **Big.** The symbol fills **about 80% of the canvas**, centered, with a little clear space all
  round. It is the only thing in the picture.
- **A thick ivory border hugging the symbol's own silhouette, like a die-cut sticker** — about a
  **twelfth of the canvas thick**, the same thickness all the way round, following every point and
  curve of the shape. The border is pale ivory, softly shaded lighter toward the upper left. It is
  what makes a green symbol read on green jade and an orange one on amber, so **it must be unbroken
  and clearly visible all the way round**.
- **A thin dark contour just outside the border**, about a hundredth of the canvas, so the whole
  sticker holds its edge on any background.
- **The symbol inside the border is in its element's colors**: smooth shading from the ramp's
  `light` toward the upper left to its `dark` away from it, the `core` between, with a soft polished
  sheen — the same finish as the stone buttons. One or two simple inner shapes at most, in the same
  ramp, to give it form.
- **Chunky shapes only.** These are used at 44 pixels across. Nothing in the symbol may be thinner
  than about **a seventh of the canvas** — no thin lines, no small details, no spikes, no
  filigree. **Reduced to 44 pixels, each must still be its shape.**
- No glow, no halo, no cast shadow, no sparkle, no background, no coin, no frame, no button.

**The five are one set.** Same border thickness, same contour, same finish, same overall size —

### The canvas

Each file is **exactly 256 x 256**, a **transparent** PNG with an alpha channel. Work as large as
you like and reduce once to 256 on the way out.

Avoid: text, letters, numbers, labels, coins, discs, frames, backgrounds, scenery, glow, sparkle,
thin lines, small details, and any heavy black outline.

## Before you hand anything back

1. **Lay each icon on the jade button and on the amber button, and reduce both to 44 x 44.** Is it
   still unmistakably a flame, a snowflake, a lightning bolt, a mountain, a crescent with an orb?
2. **Is the ivory border visible all the way round every icon at 44 pixels**, on both stones? Is the
   green mountain clearly readable on the green jade?
3. **Is the snowflake perfectly six-fold**, its six arms equal and evenly spaced, each with its
   forked tip?
4. **Line the five up side by side.** Same border, same size, same finish — one family?
5. **Is everything outside each icon's contour fully transparent**, with no halo?

Name the five files exactly as in the table, each ending `.png`, and give me a single zip file of
everything so I can download it all at once — never a link per file.
