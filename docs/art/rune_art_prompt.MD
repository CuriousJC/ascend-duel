# Rune shapes

**The one thing a rune prompt needs that an essence's does not.** The prompt itself is
[essence_art_prompt.MD](essence_art_prompt.MD) rather than the relic one, because a rune draws
through `cards.EssenceStyle` and carries the same sentence scrim an essence does. This file is
the body plan, pasted between that prompt and the record.

**Why it exists.** A relic is an object and can be described from nothing. A rune is not, and a
generator handed "a rune" with no body plan invents a different thing every time — which is how a
catalog of thirty-seven ends up looking like thirty-seven separate commissions.

**A shape describes a body, never a style.** Materials, shading, outline, lighting, palette,
background and composition are all settled by the essence prompt and are not to be restated here;
a shape that argues with the style block is two prompts disagreeing inside one paste.

## Shape — one entry, pasted verbatim

**Not yet written.** The shape list is a closed list of body plans, one of which every rune picks
exactly one of — a rune that does not fit one is a signal to argue for another entry, not a
license to write a new body plan inline. An inline shape is the whole failure this file exists to
prevent.

## The subject — written per rune

Say what makes this one that shape and not its sibling — color, ornament, what the effect is
doing to it. One paragraph. The prompt never names the rune and the shape never distinguishes two
of a kind, so everything that tells `Embermark` from `Rimemark` lives here.
