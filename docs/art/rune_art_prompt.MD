# Rune shapes

**The one thing a rune prompt needs that a relic's does not.** The prompt itself is
[card_art_prompt.MD](card_art_prompt.MD) — pasted with its **upper band** composition block,
because a rune draws through `cards.EssenceStyle` and the text band covers everything below
y 140. This file is the body plan, pasted between the two.

**Why it exists.** A relic is an object and can be described from nothing. A rune is not, and a
generator handed "a rune" with no body plan invents a different thing every time — which is how a
catalogue of thirty-seven ends up looking like thirty-seven separate commissions.

## Shape — one entry, pasted verbatim

**Not yet written.** The shape list is a closed list of body plans, one of which every rune picks
exactly one of — a rune that does not fit one is a signal to argue for another entry, not a
licence to write a new body plan inline. An inline shape is the whole failure this file exists to
prevent.

## The subject — written per rune

Say what makes this one that shape and not its sibling — colour, ornament, what the effect is
doing to it. One paragraph. The prompt never names the rune and the shape never distinguishes two
of a kind, so everything that tells `Embermark` from `Rimemark` lives here.
