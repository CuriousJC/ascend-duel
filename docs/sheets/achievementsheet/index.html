Achievement sheet

27 achievements, 0 of them drawing the default icon, 0 with no subject paragraph written, 0 hidden.

Regenerate with go run ./tools/achievementsheet and refresh. Every field is read out of data/achievements.json through internal/achieve's own validation.

The fields under each name are Steamworks' own, under the names its admin page uses, so this page is what that page is filled in from. The two 256px icons are the upload files: achieved-*.png is the Achieved Icon and unachieved-*.png the Unachieved Icon. The gray one is derived, by systems.ArtMarkGray — the same call that draws a locked row in the game.

Judge an icon at 64px, not at 256. That is the size Steam's pop-up and the game's achievements page both draw it, and the small pair is reduced by the game's own averaging rather than by the browser.
