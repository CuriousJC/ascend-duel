Essence sheet

15 essences, 0 of them drawing the default face, 0 with no subject paragraph written. 2 are offered after a won fight — 13.3% of the catalog gets a seat. Essence card 200×280, corner radius 15, border 4, art box inset 0 from y=0 at most 0 tall, text band from y=164. Shown at 1:1 on the ground the essences are actually offered on.

Regenerate with go run ./tools/essencesheet and refresh. Every card here is drawn by internal/cards, the same code the game blits, and every word beside it is read out of data/essences.json through internal/session's own validation — so a essence this page refuses to draw is an essence the game refuses to start with.

Read the sentence against the rule. The line under each name is the Text field, which is what the card prints verbatim; the monospace line under it is the rule that actually fires. Nothing in the codebase checks one against the other.

The subject paragraph is the art brief, and it lives on the record. The quoted block under each essence is Draw in data/essences.json: what the thing is and what it is doing, in one sentence. Nothing in the game reads it. It is pasted under the catalog's own prompt, docs/art/essence_art_prompt.MD, which is the only part of a brief that is not about one record. An essence with no subject and no art is the backlog — both lines go pink, so the page can be scrolled for what still needs writing rather than a worklist being kept in step by hand. default-essence.png is the seat art goes into, not a fallback that has gone wrong.

What the catalog changes

Every target, and how many essences sit at it. The target vocabulary is closed — a new one is a Go change plus one place applying it, never something a file can assert into existence — so a target with nothing under it is a mechanic that was built and never reached for. This was the page's grouping until families landed; it is a count now, because the target is a fact about one essence and a family is a block of them.

The catalog, by family

Grouped by the motif each essence was authored beside, in the file's own order. Family is authored and the engine ignores it, exactly as it ignores Art and Draw — so it can go quietly out of date when an essence is retargeted, and nothing fails. Treat a family that disagrees with the rule beside it as a label to fix.
