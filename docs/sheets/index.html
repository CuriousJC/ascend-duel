Review sheets

Generated pictures of what the game's catalogues actually hold. They are committed, so this page opens from a bare clone with no Go toolchain — but that also means they are only as current as the last run of go run ./tools/sheets. Regenerate after changing a catalogue, and not otherwise.

Every card on every sheet is drawn by internal/cards, the same code the game blits, so a sheet cannot show a card the game would draw differently.

Card sheet
Every card variation, plus the backs, the states and the deck rows. **A drawing-board rather than a report** — it writes its own contents out, so it can show cards the rules cannot deal yet.
Ring sheet
Every ring, grouped by rarity, with its price, the sentence it prints and the rules that actually fire side by side. The only place the authored line and the rule can be read against each other.
Worm sheet
Every worm, grouped by what it changes about a card. Two are offered after a won fight, so this is the whole catalogue a run sees a fifth of.
Hand sheet
Every rung of the hand ladder drawn as an actual hand of real cards, ordered by multiplier across all three axes at once — which is the comparison hands.json's axis-by-axis layout hides.
Glyph sheet
Every generated glyph by every palette, drawn at the scale a card uses it and again enlarged. One committed PNG, so a change to a silhouette shows up in review as a picture.
