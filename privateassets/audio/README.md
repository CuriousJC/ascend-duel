# privateassets/audio

The game-ready sounds, mirrored here by `privateassets/mgmt/sync-from-drive.ps1` and fetched by a
release. Nothing else in this directory is in git: what belongs here is `music/`, the tracks
[data/music.json](../../data/music.json) names, and `sounds/`, the effects
[data/sounds.json](../../data/sounds.json) names, and [../README.md](../README.md) says how they get
here.

This file is committed because `//go:embed audio` needs the directory to exist.
